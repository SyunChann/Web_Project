# Pixel Agents credits

This embedded office is based on [Pixel Agents](https://github.com/pixel-agents-hq/pixel-agents) version 1.5.0.

Pixel Agents source code is licensed under the MIT License. The complete license text is included in `LICENSE`.

Character sprites are based on the MetroCity Free Topdown Character Pack by JIK-A-4, as credited by the upstream project.

The embedded build removes terminal, chat, agent-launching, and WebSocket features. It keeps the Canvas 2D office renderer, pathfinding, animations, and bundled office assets.
